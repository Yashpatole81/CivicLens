# CivicLens PRD

*Turn a photo into action. Make your city better.*

Product documentation for CivicLens, an AI-assisted municipal complaint app built for the Meta Global AI Developer Hackathon. India-first (English UI, Android), with Stockholm also seeded. **Documentation only.** Nothing described here has been built, provisioned, or integrated yet.
